# work-public-pages

这是 [`scarlettii/work`](https://github.com/scarlettii/work) 私有源仓库中「AI 技能购买相关优化」原型的**公开发布仓库**，用于 GitHub Pages。私有源仓库继续保存工作文件和版本记录；本仓库只保存向公众开放的网页文件。

- 网页地址：<https://scarlettii.github.io/work-public-pages/>
- 私有源仓库目录：`ai-skill-purchase-optimization/`
- 维护方式：先在私有源仓库更新原型，再同步本仓库的 `index.html`、`styles.css`、`app.js`、`screens.js` 和 `images/`。修改文案和标注时编辑 `screens.js`。

本网页包含页面截图和标注，图片位于 `images/`。
